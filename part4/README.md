# HBnB - Simple Web Client (Part 4) 🏡

## Description
This is Part 4 of the HBnB project (AirBnB clone). In this phase, we focus on the **Front-End Development** of the application. The primary goal is to build an interactive, dynamic user interface using HTML5, CSS3, and JavaScript (ES6), and seamlessly connect it to the back-end API developed in the previous phases.

## Objectives
*   Develop a user-friendly interface following specific design guidelines.
*   Interact with back-end API services using the `Fetch API`.
*   Handle user authentication and manage sessions securely using **JWT** and **Cookies**.
*   Manipulate the DOM to enhance user experience without full page reloads (SPA logic).
*   Handle and configure CORS (Cross-Origin Resource Sharing) on the Flask API.

## Project Structure
*   `index.html`: Main page displaying a list of all available places with a client-side price filter.
*   `place.html`: Detailed view of a specific place, including amenities and user reviews.
*   `login.html`: User login form to obtain authentication tokens.
*   `add_review.html`: Form to add a review for a place (restricted to authenticated users only).
*   `styles.css`: Global stylesheet containing mandatory parameters for layout and design.
*   `scripts.js`: Client-side JavaScript handling API requests and DOM updates.

## Technologies Used
*   **Front-End:** HTML5, CSS3, Vanilla JavaScript (ES6)
*   **Back-End:** Python 3, Flask, SQLAlchemy
*   **Authentication:** JWT (JSON Web Tokens)
